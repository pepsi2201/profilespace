# ProfileSpace

### Windows
1. Установи Node.js 18+.
2. Распакуй архив.
3. Запусти `START.bat`.
4. Открой `http://localhost:3000`.

### Терминал
```bash
npm install
npm start
```

**Важно:** не открывай `public/index.html` двойным кликом — многопользовательская регистрация требует Node.js сервера.

База `data.sqlite` создаётся автоматически.
